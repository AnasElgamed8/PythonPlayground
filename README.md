### Python Playground

Hello! Welcome to my playground!

I've always wanted to learn Python. I tried learning by following the traditional way of learning fundmentals, then solving random competetive programming questions. But this method never clicked for me.

I've decided to try another way. Working on small, fun projects. And this repository is basically the archive for all the ideas I've worked on.

I initially planned on making this a private repository like I usually do, but I decided leaving it public would be better. Just in case someone is struggling with finding ideas on their own, and wants to find some inspiration by looking at the ideas I worked on.

Have fun!
